# Hidden variant audit — v0.1.13

Adds 45 kit definitions: 12 armour bodies and 33 helmets. Their kit IDs and archive IDs are distinct; shared localization names are not duplicate identities. The six user screenshots demonstrate visible recolours, but do not expose IDs, so individual colour-to-ID matching is not claimed.

Selection uses the captured 411-kit catalogue plus the previously downloaded community archive mapping. Selected families: SC-37 Legionnaire, SC-30 Trailblazer Scout, B-24 Enforcer, FS-05 Marksman, SC-34 Infiltrator and B-01 Tactical (including one TBD helmet in that family). Some bodies are development/NPC alternatives and remain experimental. Asset references alone do not prove a working preview or equippable model.

Explicit ordinary exclusions (original kit indices): Legionnaire 82/85; Trailblazer 98/102; Enforcer 108/110; Marksman 113/117; Infiltrator 124/127; standard Tactical bodies 136–139 and helmets 149–152. The archive mapping identifies the player Marksman and Legionnaire/Enforcer bodies separately from their alternatives. Existing ordinary kit flags remain untouched.

Names in logs/catalogue include the hexadecimal kit ID for diagnostics. The game UI still uses its existing shared localized names; no global localization strings are overwritten. This is an explicit allowlist, not an exhaustive claim about every game asset.
